孔传负责解释0.1：任务字段、模型参数提取、规则回退、优先级公式、按天分配、SQLite/IPC链路和已知问题。汇报可本人进行或王浩宇代讲，不据此改变实际贡献归属。

王浩宇先完成共享规划基础：问题修复、时间语义迁移、工具注册、模型行动循环、Run状态/恢复、记忆查询、课表与调度、今日对话和后台消息。复杂统计、向量索引、托盘、邮件等按方案优先级后置。

罗德金随后开发作业助手：文字/公式输入、按需提示和讲解、资料查询、知识卡、原题重做；再接OCR图片识别/校对，最后提出复习任务草案交给规划入口。

## 2. 作业助手接入前的里程碑

| 阶段 | 王浩宇先交付 | 罗德金可开始的工作 |
|---|---|---|
| A：契约 | 共享类型、工具Schema/结果格式、错误码、Run状态与模拟接口文档 | 准备验收题和界面；用明确标注的替身数据开发 |
| B：最小Harness | start/resume/cancel、查询工具、模型观察循环、等待/确认消息 | 用真实共享内核接入作业场景，不自行复制另一套循环 |
| C：数据与规划 | 受控DAO/迁移、记忆检索、试排/校验/提交、版本和幂等规则 | 对接知识卡/复习记录及propose_review_tasks |
| D：联调 | 今日消息/操作卡、错误恢复、运行日志与测试库 | 作业→复习草案→确认→日程完整演示 |

开工前双方确认A阶段文档，再并行开发；不要求罗德金一直等所有规划功能完成。接口在真实实现前均属于建议，不能直接引用不存在的导出。

## 3. 拟议模块与所有权

```text
src/main/agent/       共享Harness、工具注册/执行、Run（王浩宇）
src/main/memory/      检索与来源/版本管理（王浩宇）
src/main/planning/    课表、估时、调度与校验（王浩宇）
src/main/study/       作业域工具、OCR适配器、学习记录（罗德金）
src/main/db/          共用连接和迁移总入口（王浩宇统筹）
src/shared/           共享类型/协议（王浩宇统筹，双方先对齐）
src/renderer/        今日/日程由王浩宇，作业/复习/OCR页面由罗德金
```

main/agent、main/planning、main/memory和main/feedback已在开发分支实现，main/study仍待开发。记忆字段与估时分组均使用分组原文，不加course:前缀。罗德金提供学习相关表结构/迁移草案，由迁移总入口统一编号，不独立创建另一份数据库或复制模型密钥管理；作业自评不等同实际专注耗时，需分开存储。

## 4. 必须对齐的契约

- 工具返回`ok/data/errorCode/message/sourceRefs/stateVersion`；调用参数先运行时校验，再执行。
- UI通过preload/IPC启动Run，工具在主进程内部直接调用服务/DAO，不从模型请求任意SQL或本机路径。
- 只读查询按范围返回必要信息；写入使用可信授权、版本检查、短事务和幂等键。
- 作业建议只产生任务草案（题目/知识卡证据ID、内容、估时、窗口），用户确认后由规划侧建任务和排期；返回实际任务ID防重复。
- OCR使用已上传imageId，确认校对稿后分析。原图、识别稿、确认稿保留修订关系。
- 模型分析、用户自评、确认事实、算法统计各保留来源，不能混为确定的个人画像。
- 测试使用独立数据；假接口/回放与真实模型结果分别记录。

## 5. Git协作方式

各自clone本仓库。王浩宇建议用`feature/planning-agent`，罗德金建议用`feature/study-assistant`；这些是未来分支名建议，不表示远端已创建。开始工作前更新main，然后创建自己的分支。

```powershell
git switch main
git pull --ff-only
git switch -c feature/study-assistant
```

小步提交，一次一个明确改动；合并前说明改了什么、接口变化、验证方法和未完成项。共享迁移/工具注册/类型变更先对齐，避免分别改好再整段覆盖。不得提交个人API Key、数据库、node_modules或生成的安装包。
