## 已知行为与问题

1. `shared/priority.ts`的`isOverdue`引用未定义变量`dueAt`而非`task.dueAt`，可能导致有日期任务的今日页渲染失败。尚未修复，应作为开工第一项；构建通过不代表此问题消失。
2. AI每日重评复用通用updateTask，会设置人工锁，需拆分自动/手动更新语义。
3. `dueAt`混合外部截止和计划日期；按天调度用23:59，固定240分钟软上限且存在回卷。改版要明确迁移旧字段来源。
4. 当前client只返回文本，没有原生tool_calls消息处理、注册表或Agent循环；MCP未接入，也不计划首版接入。
5. 统计页只有基础数量；通知/局域网设置不表示执行服务已接通；新作业/OCR/课表/记忆功能均未实现。
6. 旧`test-ai.js`主要复制规则逻辑，`test-e2e.js`不是完整真实端到端测试且含直接操作plan.db的路径。本交接不收录这些脚本，也不将它们当作新版验证证据。
