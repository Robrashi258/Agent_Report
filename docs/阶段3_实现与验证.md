# 阶段3：确认记忆、个人估时与后台完成回顾

日期：2026-11-05；版本：0.2.0-alpha.3；分支：feature/planning-agent。

## 1. 当前已实现的体验

- 个人记忆：手动新增、修改内容/有效期、移除；对话可提出记忆草案，用户确认后才保存。
- Agent按需调用search_memory检索相关确认记录，返回来源、版本和有效期；不是每次把全库注入模型。
- 同估时分组、同原始估时来源的执行反馈用于校准；新试排采用校准值，任务原始估时和已有执行块保留。
- 点击完成先在本地事务中保存完成状态和事件/队列，模型请求稍后在后台执行，界面不等待模型。
- 后台模型可自行检索相关记忆，再选择silent或ask。silent不发任何消息；ask只在今日留下可忽略的消息和未读标记，不弹窗、不发送系统通知、不切换当前页面或聊天。
- 已读、已回答、忽略、过期和撤销完成分别记录。回复采用结构化耗时/难度/补充表单，不要求用户填满所有项，也不会自动把补充回答写成长期画像。

## 2. 使用顺序

1. 到“个人记忆”添加确认信息，例如分组“数学分析”、名称“学习阶段”、内容“目前初学，需要先理解例题”。不加course:之类命名空间前缀。
2. 在任务“时间设置”指定估时分组，如“数学分析”；同类任务使用一致分组。不同分组/来源不会混算，别名暂不自动合并。
3. 正常完成任务，不需先填反馈。需要补充时今日入口显示红色未读数；留在其他页继续操作也可以。
4. 到今日点击“查看并回复”后清除未读，问题仍保留。填写一项或多项反馈后保存；也可忽略。
5. 即使模型没提问或未配置模型，也可在已完成任务卡上点击“完成反馈”手动记录。旧版完成记录没有估时快照，不补造历史样本。
6. 后续同组任务显示个人估时、原始估时和样本量；试排会采用个人估时并向上对齐15分钟。关闭个人校准会回到原始估时，但保留反馈记录。

“个人记忆”页提供后台追问和校准两个独立开关。关闭追问取消未处理评估并忽略未回答消息，不影响已完成状态、已存反馈或手动填写。

## 3. 技术架构与数据

迁移v8增加任务base_estimate_min、estimate_group、estimate_source、completion_seq；增加memory_facts、profile_settings、completion_events、completion_feedback、completion_jobs、followup_messages。升级前按最新版本生成before-v8一致性备份；旧数据只回填原始估时，不编造实际耗时/完成事件。

```text
点击完成
  → 短事务：任务done + 新完成周期 + 冻结估时事件 + 唯一队列项
  → 返回界面并刷新任务
  → 400ms后唤醒后台串行处理（前台Agent繁忙时让行）
  → 模型读取事件与校准摘要，可选择检索相关记忆
  → respond(silent)：结束，无消息
  → respond(ask)：再次检查有效性，写唯一站内消息
  → PROFILE_IPC.changed → 今日红点/消息刷新，不触发通用Agent对话切换
  → 用户填写反馈 → 保存记录，消息answered，后续估时/试排更新
```

完成周期递增；重复提交done不增加事件。撤销完成将相关事件失效、取消队列/消息，校准查询也排除它。再次完成是新周期，不复用旧反馈。样本查询同时检查事件valid、任务done、当前周期一致。

后台仅允许search_memory和respond，不开放改计划/写记忆/数据库工具。其模型循环独立于今日通用对话，评估痕迹保存在completion_jobs.trace_json（模型、轮次、检索引用、决策），不保存内部思维链或密钥。

## 4. 记忆检索与RAG范围

确认事实保存在SQLite，唯一键为规范化scope+key；带版本、来源、更新时间和可选有效期。修改先检查版本，过期/删除立即不再检索。用户手动记录和用户确认的模型建议分别标记来源。

本阶段采用精确分组过滤、关键词/中文双字片段匹配与相关性排序，返回前1—5条；不是向量检索，不调用Embedding API。读取候选最多2000条，界面最多列500条，适用于当前小型个人库，未做大规模检索评测。

模型可根据工具观察改查询；错误分组返回UNKNOWN_MEMORY_SCOPE并提示去掉scope重查，不能把拼错分组直接解释成“没有记忆”。搜索无命中如实为空，不补造用户信息。固定记忆文本是数据，不能授权越权工具操作。

新增get_feedback_history按分组读取最多5条有效单次执行证据，包含用户补充和completion引用，与确认事实分开；一次觉得难不等于永久学不会。estimate_duration返回校准摘要；propose_memory生成草案，由UI确认后写入。

## 5. 校准算法与计划一致性

任务baseEstimateMin保持原始值；estimateSource区分用户确认、模型、规则和迁移历史。自动再分析不能覆盖用户确认的原始估时，已排期任务的耗时也不被悄悄改写。

对同分组、同来源最近10个有效反馈：`r=实际专注分钟/该次冻结原始估时`；用于计算时截断至[0.5,2.5]，取中位数m，n为样本量。

```text
w = n / (n + 5)
k = 1 + w × (m - 1)
个人估时 = 向上取整到5分钟(原始估时 × k)
```

无样本k=1。例：5次均为原始60、实际90，k=1.25，个人估时75；仅1次相同反馈时约65分钟。两者都是机制示例，不能证明长期效果。过大的校准结果不截掉工作量，交给试排提示需要用户拆分。

实际分钟由用户填写，不能用创建至完成的自然时间或计划块长度替代。难度不另乘一次系数。中断耗时不确定、任务范围变化、缺实际分钟的记录保留，但不进入估时样本。编辑旧反馈会更新其样本排序；撤销完成立即剔除。

计划快照版本包含校准数据和开关；新反馈使未提交的旧预览失效。已有确认执行块不自动扩缩、移位或覆盖锁定；用户可重新试排。规划仍以硬截止、课程和容量为约束。

## 6. 无打断、去重与恢复

- 默认每天最多3条新问题、12个完成事件评估；每事件最多2次尝试，每次最多4轮模型决策，整体70秒、单请求30秒。
- 队列按事件唯一，领取有token和120秒租约，串行执行。崩溃后过期租约可重领；退出时释放本进程租约并取消请求。失败30秒后重试一次，不撤销完成，不产生错误红点。
- 消息按事件唯一。发布前再次核对token、开关、任务状态/周期、用户是否已手动反馈和有效期。在途时撤销/关闭/先手动反馈，都不会发布迟到问题。
- 完成24小时后不再补问，问题也到期；忽略后不就同一事件重问。读取只清未读，不伪装成已经回答。
- 页面未配置模型时队列等待；不让规则兜底伪装成模型决定，不清掉已完成任务。失败项可以明确点击重试。
- PROFILE事件只刷新消息/估时，不自动打开消息、不弹窗、不抢输入焦点。新问题可忽略，个人记忆写入始终另行确认。

## 7. 验证与实际发现

隔离测试覆盖确认记忆检索、过期/删除、并发版本、记忆确认、中位数手算、小样本收缩、完成事务回滚、事件去重、跨组/来源隔离、样本有效性、撤销重做、校准后的试排及预览失效、silent/ask、后台RAG、已读/忽略/关闭、重复回复、迟到响应、有限重试、租约恢复、每日上限和前台让行。

真实千问第三阶段场景：检索确认记忆并回答“初学”；读取原始60、5次实际90的校准结果75；后台自主评估完成事件（本次真实结果为asked）。允许模型选择silent，不以必须追问作为智能或通过标准。

命令：`npm test`运行隔离回归；`npm test -- --live --profile-live`在隔离回归后只运行上述3个第三阶段真实场景，减少重复API消耗；不带profile-live时还会运行前两阶段真实场景。需要AGENT_TEST_KEY_FILE，仅使用合成任务，结束时清空测试凭据。最终数量以实际运行输出为准，不声称总体准确率。

开发中发现并处理：模型自创course:分组导致空检索，工具改为返回可纠正错误；模型以规划追问替代已找到的事实，补充先回答事实的交互约定；实际数字输入被浏览器转为number，反馈表单原先调用trim报错，已改为统一归一化后保存并进行原生界面复测。

原生窗口已验证：手动确认数学分析初学记忆；在“全部任务”点击完成后立即变为3项进行中；真实模型稍后使今日出现1条未读，仍停留原页且输入草稿保留，无弹窗；查看后红点清除但问题仍在；保存实际专注90分钟后消息进入已处理，同组下一项任务显示个人估时65、原始60、1个有效样本。关闭重开后记忆版本1、反馈90、answered/is_read状态与个人估时均保留；队列仍为asked/attempts=1，没有重复追问。迁移v7隔离副本时自动生成了before-v8备份。

最终检查：类型检查与构建通过；聚焦第三阶段的真实命令共64项通过（61项隔离回归+3项第三阶段真实场景）。随后完整`npm test -- --live`共69项通过（61项隔离回归+前后三阶段8项真实场景），后台真实决策为asked。该结果不是首次通过率或稳定成功率。

## 8. 协作与后续

main/memory负责事实、检索与校准；main/feedback负责事件反馈、消息和后台评估；通用Harness仍在main/agent，读取/确认工具和MemoryChange已接入。罗德金可复用分组、事实来源和完成反馈概念，但作业自评与实际耗时是不同数据，不要混用字段或将一次答错当稳定画像。

本阶段仍不包含作业/OCR、邮件、课后主动检查、向量索引和自动学习偏好。新消息通过结构化表单回复；尚未把任意自由聊天自动解析为耗时记录。确认记忆可在正常对话检索或提出草案，单次反馈则由get_feedback_history查询。
